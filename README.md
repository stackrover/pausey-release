# Pausey

Break reminders and focus modes for macOS and Windows. Pausey lives in the menu bar (macOS) or the system tray (Windows). It reminds you to rest your eyes and move, and it stays out of the way during meetings, games and free time.

## Download

Get the latest installer from [Releases](../../releases/latest):

| Platform | File |
|---|---|
| macOS 13+ (Apple Silicon and Intel) | `Pausey_<version>_universal.dmg` |
| Windows 10/11 (x64) | `Pausey_<version>_x64-setup.exe` |

## Install

**macOS**
1. Open the `.dmg` and drag **Pausey** onto **Applications**.
2. Open Pausey from Applications. This build is not yet notarized by Apple, so on first launch right-click **Pausey.app**, choose **Open**, then **Open** again. Alternatively, go to System Settings › Privacy & Security and choose **Open Anyway**.

Pausey appears in the menu bar and opens automatically at login. You can turn that off in Settings › General.

**Windows**
1. Run `Pausey_<version>_x64-setup.exe`. It installs for your account only, with no admin prompt.
2. This build is not yet code-signed, so SmartScreen may warn you. Choose **More info › Run anyway**.

## What it does
- **Microbreaks** (every 15 min, 20 s) and **extended breaks** (every 60 min, 1 min). Only active time counts, and missed breaks never pile up.
- **Modes you switch yourself:**
  - **Normal** and **Gaming**, each with its own timing.
  - **Meeting**, which pauses breaks until you end it.
  - **Relax**, for the length you choose, followed by a gentle reminder with your favourite apps.
- A calm full-screen break screen on every monitor. Hold **Esc** for 3 seconds to end any break; Pausey never locks your computer.
- Skips the full-screen break during full-screen apps and remote sessions.
- Audio output and input switching (macOS), launch at login, and global shortcuts.
- Private: everything stays on your computer, with no account and no analytics.
